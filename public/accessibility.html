Accessibility

The directory should work for everyone.

You can find and read the reviewed directory without using the 3D globe, precise pointer movements, motion, color, or location access.

1. Our commitment

Real World Needs aims to serve people with disabilities and people who use assistive technology, a keyboard, browser zoom, reduced motion, or a small screen. We are working toward Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

This is a goal, not a claim that the site has passed an independent accessibility audit. We will continue testing and improving the directory as it grows.

2. Accessibility features

  • a skip link and semantic headings, landmarks, navigation, lists, buttons, and labels;
  • visible keyboard focus and keyboard-operable search, filters, resource rows, map links, save, share, print, and download controls;
  • plain-language status messages exposed to assistive technology;
  • text alternatives for icons and a textual directory alternative to canvas content;
  • responsive layouts and readable text that support browser zoom;
  • reduced-motion support, a pause control, and no required auto-rotation when reduced motion is requested;
  • aid categories identified by text as well as color; and
  • large touch controls for the most important mobile actions.

3. Using or bypassing the globe

The globe supports arrow keys to rotate, plus and minus keys or buttons to zoom, and a reset control. On touch devices, drag rotates and a two-finger pinch zooms the globe while the surrounding page remains zoomable outside the interaction area.

The 3D view is supplementary. You never need to operate it to search, filter, read, save, share, print, download, or open directions. Use the directory list immediately below the globe when a canvas interface is not appropriate for you.

4. How we test the site

Before releases, we check keyboard use, reduced motion, text zoom, narrow mobile layouts, touch gestures in Chromium mobile emulation, page structure, browser errors, links, security headers, and the text-only directory. Our goal is WCAG 2.2 Level AA alongside practical testing with the tools people use.

5. Known limitations

  • Country borders and country selection on the globe are visual. The same services can be found in the text directory.
  • Long organization names, addresses, and source information can be harder to read or navigate.
  • External organization and map websites are outside RWN’s control and may not meet the same accessibility goal.
  • Natural Earth borders are simplified map data and should not be used for legal or navigation decisions.

We do not currently know of an issue that prevents access to the text directory. That does not mean every browser and assistive-technology combination is free of problems.

6. Accessibility feedback

RWN does not yet have a verified public accessibility contact. Until one is available, use the text directory if the globe is difficult to operate. If the problem is on an organization’s website, contact that organization through its original-source link.

What still needs to be added: a monitored accessibility contact with a named person responsible for replies. We will publish it here after it has been established.
