# Final Perfection Audit Matrix

## Protected Baselines

The established RWN brand mark, color system, calm editorial hierarchy, verified service data, detailed globe, zoom behavior, marker continuity, scroll ownership, offline strategy, cache-safe release asset versioning, and existing accessibility contracts are not redesign targets. This pass may refine them only where a measured inconsistency or friction point is found.

## Fresh-Eyes Journeys

| Journey | Review focus | Evidence required |
| --- | --- | --- |
| Homepage to core need | Above-fold purpose, search clarity, category order, result transition | Desktop, tablet, and 320 px screenshots; keyboard pass |
| Search to service and back | Input stability, result update, direct task action, history restoration | Browser interaction QA |
| Directory to service | Density, scanability, filters, direct landings, long-content cases | Directory and service browser QA |
| Location and offline | Calm human recovery, retry, precise disclosure, resilient unavailable states | Location/offline browser QA |
| Globe discovery | Marker legibility, controls, fallback, result handoff, no scroll conflict | Globe QA plus fresh cache browser inspection |
| Editorial and policy pages | Reading width, type hierarchy, footer/header consistency, direct landing | Screenshot review and text-structure check |

## Not Quite Right List

Potential findings are accepted only when reproduced through a rendered journey, responsive capture, source audit, or browser test. Examples include visual drift, excess density, clipped focus, avoidable text, unclear recovery copy, abrupt motion, awkward wrapping, cache artifacts, and component-state inconsistency.

## Quality Gates

The release must pass build, data validation, unit tests, directory QA, globe QA, interaction QA, abuse QA, offline QA, browser QA, responsive viewport review, 320 px review, high-zoom/reflow checks, fresh-cache production verification, and no-console-error inspection. The required output is `FINAL_PERFECTION_PASS_REPORT.md`, including deliberate restraint and known limits.
